## 4. 商業環境(TG=トラフィックジェネレーター)

- **駅ビル**: エキア志木(EQUiA、2017年リニューアル)
- **東口**: マルイファミリー志木(徒歩1分、高架デッキ直結、志木市最大の商業施設)、マルエツ・TAIRAYA(24時間)・ビッグ・エー等のスーパー群
- **南口**: イオン新座店(徒歩約3分)、新座志木中央総合病院(徒歩約5分)
- **バス**: 国際興業・東武バスウエスト・西武バスが両口から発着
- **鉄道利便**: 池袋まで約17分(東上線急行停車駅)。立教大新座キャンパス・慶應志木高の学生流動あり
- **街の性格**: 駅直近に商業集積、外側は高密度住宅地のベッドタウン型。駅前で買い物が完結する構造 = **駅がTGとして強く機能**
- 出典: Wikipedia「志木駅」、アットホーム タウンライブラリー https://www.athome.co.jp/town-library/saitama/shiki-st/

楽笑整体院(南口徒歩3分)は「駅(TG)→イオン新座(TG)→住宅地」の南口動線圏内。
