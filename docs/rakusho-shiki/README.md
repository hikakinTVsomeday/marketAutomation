## 結論(TL;DR)

- **エリア選定は正解**: 需要側の指標(乗降客数・商圏人口・所得・商業集積)はほぼ満点。
- **競合密度だけが基準超過の激戦区**(同業81件、基準は20件以上で激戦)。ただしこれは市場成立の証左でもある。
- **課題は立地ではなく口コミ資産**: 口コミ15件 vs 上位競合1,313件。目的来店型業種の勝敗はWeb上の発見可能性で決まるため、MEO・口コミ獲得が集客戦略の主戦場。
- **移転は不要**。新規で選ぶなら朝霞台・朝霞がわずかに有利だが、差は移転コストを正当化しない。
